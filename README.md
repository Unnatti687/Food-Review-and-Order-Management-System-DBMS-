# 🍔 Food Review and Order Management System — BigHungers

A DBMS academic project focused on organizing food ordering operations, restaurant information, menu items, orders, delivery assignments, and payment records through a structured database-driven system.

🌐 **Live Demo:** [BigHungers — Food Ordering Website](https://food-ordering-frontend-one-eosin.vercel.app/)

## 📌 Project Overview

The Food Review and Order Management System is designed to simplify online food ordering by bringing customers, restaurants, and delivery operations together in one platform.

The project explores how database management concepts can support an online food ordering workflow, from browsing restaurant menus to maintaining order and payment records.

The frontend is deployed on Vercel and built with React.js.

## 🎯 Objectives

- Organize user, restaurant, menu, order, and payment data.
- Support a structured food ordering workflow.
- Model relationships between database entities.
- Apply primary keys, foreign keys, constraints, and normalization.
- Explore database transactions, triggers, and stored procedures.
- Provide a user-friendly interface for browsing food and placing orders.

## 🗄️ Database Design

The report describes seven core relational entities:

1. **USER** — user details and account information
2. **RESTAURANT** — restaurant details and ratings
3. **MENU_ITEM** — food items, prices, and availability
4. **DELIVERY_PARTNER** — delivery personnel and availability
5. **ORDERS** — order details, totals, and status
6. **ORDER_ITEM** — items and quantities associated with each order
7. **PAYMENT** — payment methods, statuses, and transaction dates
